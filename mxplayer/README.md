# MaxPlayer

MX Player 스타일의 가볍고 빠른 모바일 동영상 플레이어 (PWA, 의존성 0, 오프라인 동작).

## 실행
HTTPS로 호스팅(GitHub Pages 등)한 뒤 모바일 Chrome에서 열고 "홈 화면에 추가"하면 앱처럼 설치됩니다.
로컬 테스트: `cd mxplayer && python3 -m http.server 8000`

## 기능
- 제스처: 탭(UI 토글) · 좌/우 더블탭 ±10초(누적) · 가운데 더블탭 재생/정지 · 가로 스와이프 탐색 · 왼쪽 세로 밝기 · 오른쪽 세로 볼륨(최대 200%) · 길게 누르면 2배속 · 핀치 줌
- 재생목록(여러 파일 선택, 자연 정렬), 이어보기, 반복(한 개/전체), A-B 구간 반복, 취침 타이머
- 자막: SRT/SMI/VTT/ASS, UTF-8·EUC-KR 자동 감지, 싱크·크기 조절, 같은 이름 자동 매칭
- 속도 0.25~4x, 화면 비율(맞춤/채우기/늘리기/원본), 화면 잠금, 전체화면/회전, PIP, 캡처, 화면 꺼짐 방지, 미디어 알림 컨트롤

## 최적화
- 파일을 메모리에 올리지 않고 Blob URL로 스트리밍, 전환 시 URL 해제
- UI 갱신은 재생 중에만 약 10Hz, 진행바는 CSS 변수 하나만 갱신(transform), 자막은 이진 탐색
- 제스처 중에는 탐색을 미리 하지 않고 손을 뗄 때 한 번만 seek

## 제한
웹 기반이라 재생 가능한 코덱은 브라우저/기기에 달려 있습니다(MP4·H.264/AAC, WebM 등은 대부분 OK, MKV·HEVC·AC3·DTS는 기기별로 다름). 하드웨어 디코딩은 브라우저가 자동 사용합니다.
