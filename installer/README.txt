==============================================================
 Retopo Annotate 1.5 — Blender / 3ds Max 리토폴로지 툴
 (RetopoFlow · PolyStrips 방식 기능 포함)
==============================================================

[설치]
 1. RetopoAnnotate_Setup.exe 실행 → 발견된 Blender(4.2 이상) / 3ds Max 체크 → [설치]
    (관리자 권한 필요 없음, 사용자 폴더에 설치)
    - 3ds Max 는 Autodesk 플러그인 번들로 설치 (동작 확인: 2020. 2021~2026 은 직접 확인 못함)
 2. ★ 설치 후 3ds Max / Blender 를 완전히 껐다가 다시 실행 (작업은 먼저 저장)
 * 제거: 같은 설치 프로그램의 [제거]   * 명령줄: /S 자동 설치, /U 자동 제거


==============================================================
 한눈에 보기 (Blender · Max 공통)
==============================================================
 1) 타겟(하이폴리) 지정 → [리토폴로지 시작]
      또는 [스캔 → 합친 메쉬]: 선택한 오브젝트들의 표면을 스캔해 하나로 합친 리토 메쉬를 바로 생성
 2) 주석(선)을 그으면 바로 메쉬가 됨
      닫힌 도형 → 쿼드 채우기 / 메쉬를 가로지르는 선 → 컷 / 형태를 밖→안→밖 가로지름 → 컨투어 링
      그 밖의 선 → 스트립(쿼드 띠)이나 엣지 줄. 두 선 사이는 자동으로 채움
      꺾이는 곳(두 면이 만나는 모서리)에는 버텍스가 교차선에 맞춰져 메쉬가 뜨지 않음
 3) 방금 만든 결과는 +/− 버튼이나 Alt+휠(밀도), Shift+Alt+휠(스트립 폭)로 다시 만들 수 있음
 4) 수정: 주석으로 '영역 둘러싸기' → 그 영역을 [고르게 재구성] / [오프셋] / [촘촘하게] / [성기게]
          '흐름 선' → 선택 영역을 그은 방향의 엣지 흐름으로 다시 만듦
          빈 곳 둘레 버텍스 선택 → [빈 곳 채우기] (표면에 맞게, 겹침 없이)
          [떨어진 메쉬 연결] → 따로 떨어진 두 조각(또는 두 리토 오브젝트)의 마주 보는 경계를 찾아
                               표면에 맞는 쿼드로 이어 붙임. 두 조각의 경계 버텍스를 골라 두면 그 부분을 연결
 5) 촘촘하게/성기게를 일부 영역에만 해도 둘레에 5각형이 생기지 않음
    (새 엣지가 옆 쿼드들을 지나 메쉬 끝까지 이어짐 → 성기게로 정확히 되돌아감)

 선 색 표시: 초록 = 기존 메쉬에 이어짐 / 주황 = 따로 새로 생성
 되돌리기: Ctrl+Z, 다시 실행: Ctrl+Shift+Z (Max 는 Ctrl+Y 도) — 주석 결과 하나당 한 번


==============================================================
 BLENDER  (3D 뷰포트 N 키 → 사이드바 'Retopo' 탭)
==============================================================
 · 탭이 안 보이면: 편집 > 환경설정 > 애드온 에서 "Retopo Annotate" 체크

[맨 위]  타겟(오브젝트 | 컬렉션) · [리토폴로지 시작] · [스캔 → 합친 메쉬]
   컬렉션: 그 안의 보이는 메쉬 전부를 하나의 표면으로 사용

[① 그리기]
   모드: 자동 / 폴리스트립 / 컨투어 / 엣지 / 도형 채우기 / 두 선 사이 / 컷 / 영역 선택 / 흐름 재구성
   엣지 길이 [+][−] / 스트립 폭 [+][−]   → 방금 만든 결과를 새 값으로 다시 만듦
   [자동 변환] 켜짐(기본) = 선을 다 긋는 즉시 변환.  끄면 [지금 변환](Ctrl+Shift+F)
   (자동 모드) 선택된 엣지 줄이 있으면 떨어진 곳에 그은 선까지 쿼드로 연장.
               새로 시작하려면 Alt+A(선택 해제) 후 그리기

[② 수정]
   주석으로 (다음 선 한 번만):  [영역 둘러싸기] [흐름 선] [컷 선]
       누른 뒤 선 하나를 그으면 그 방식으로 처리되고 원래 모드로 돌아옴 (다시 누르면 취소)
   선택한 면 영역:  [고르게 재구성] 지우고 주변 흐름에 맞게 다시 채움
                    [오프셋] 둘레에 엣지 루프 추가
                    [촘촘하게 ×2] [성기게 ÷2] (선택 없으면 전체)
   선택한 버텍스:   [빈 곳 채우기] [주름 만들기] [쿼드 익스트루드] [표면에 붙이기] [이완] [대칭 X]
   [떨어진 메쉬 연결]  에디트 모드: 한 메쉬 안 떨어진 두 조각 / 오브젝트 모드: 선택한 리토 오브젝트들을 합쳐서 연결
   '두 선 사이' 모드: 첫 선은 주석으로 남아 있다가 두 번째 선을 그으면 사이가 채워짐

[표시] (접힘)   주석 색·두께·불투명도, 메쉬 앞에 표시(X-Ray), 와이어, 이어짐 표시
[고급 설정] (접힘)  밀도 방식(엣지 길이/분할 수/평균), 병합 거리, 표면 띄우기, 이완 반복,
                   꺾이는 곳 맞춤, 값 변경 시 바로 적용, 자동 쿼드 채우기 등

[단축키] (에디트 모드)
   Alt+휠 / Shift+Alt+휠   방금 만든 결과의 밀도 / 스트립 폭
                           (결과가 없으면 "조절할 결과가 없습니다" 표시)
   Ctrl+Alt+E / R / X      다음 선 = 영역 둘러싸기 / 흐름 선 / 컷 선
   Ctrl+Alt+F              고르게 재구성          Ctrl+Alt+O   오프셋
   Ctrl+Alt+B              떨어진 메쉬 연결
   Ctrl+Alt+ + / −         촘촘하게 / 성기게      Shift+F      쿼드 익스트루드
   Ctrl+Shift+F            주석 → 메쉬 지금 변환


==============================================================
 3DS MAX  (상단 메뉴 Retopo > Retopo Annotate)
==============================================================
 · 설치 후 처음 켜면 창이 자동으로 열림
 · 메뉴가 안 보이면: Scripting > Run Script... 에서 아래 파일 실행 (또는 리스너 F11: ra_openDialog())
     %APPDATA%\Autodesk\ApplicationPlugins\RetopoAnnotate.bundle\Contents\RetopoAnnotate.ms

[시작 · 그리기]
   [타겟(하이폴리) 선택] / [선택 오브젝트들] / 레이어 ▼ + [레이어 전체 ▶]
   [리토폴로지 시작] / [스캔 → 합친 메쉬] / [선택한 Editable Poly를 리토 메쉬로]
   그리기 방식 ▼: 자동 / 스트립 / 도형 채우기 / 두 선 사이 / 컷 / 컨투어 / 영역 선택 / 흐름 재구성
   엣지 길이 [+][−] / 스트립 폭 [+][−]  → 방금 만든 결과를 새 값으로 다시 만듦
   [주석 그리기 시작] 후 뷰포트에서 드래그, 우클릭 = 종료
     · 열린 선은 파란 '대기 선' → 이어져 닫히면 채우기 / 두 선이면 사이 채우기 /
       종료할 때 남은 선은 스트립 ([대기 선 → 스트립] [대기 선 지우기])
     · Max 의 Editable Poly 는 면 없는 엣지를 못 가지므로 선 하나는 스트립이 됨

[수정]
   주석으로 (다음 선 한 번만): [영역 둘러싸기] [흐름 선] [컷 선]  (그리기 모드가 아니면 바로 시작)
   선택한 면 영역:  [고르게 재구성] [오프셋 (루프 추가)] [촘촘하게 ×2] [성기게 ÷2]
   선택한 버텍스:   [빈 곳 채우기] [주름 만들기] [쿼드 익스트루드] [표면에 붙이기] [이완] [대칭 X]
     · 주름 만들기: 버텍스 여러 개 선택 후 → 그 점들을 잇는 경로로 컷 (가까운 점 순서로 이음)
   [떨어진 메쉬 연결]  리토 메쉬 안 떨어진 두 조각 연결 / Editable Poly 오브젝트 여러 개를 선택했으면 합친 뒤 연결

[표시] (접힘)       리토 X-Ray, 타겟 동결, 이어짐 표시, 대기 선 표시, 선/대기 색
[고급 설정] (접힘)  밀도 방식, 가로/세로/스트립 분할, 병합 거리, 표면 띄우기, 이완 반복,
                    값 변경 시 바로 적용, 꺾이는 곳 맞춤, 자동 4버텍스 구멍 채우기, 주름 옵션

[단축키]
   Alt+휠 / Shift+Alt+휠   방금 만든 결과의 밀도 / 스트립 폭 (창이 열려 있을 때)
   그리기 중 Ctrl+Z / Ctrl+Y(Ctrl+Shift+Z)   되돌리기 / 다시 (파란 대기 선이 있으면 그 선부터 지움)
   그 밖의 기능: Customize > Hotkey Editor → 카테고리 "RetopoAnnotate" 에서 원하는 키 지정
     Region Stroke / Flow Stroke / Cut Stroke / Rebuild Region / Offset Region /
     Denser / Sparser / Fill Gap / Connect Pieces / Scan Merge / Quad Extrude / Draw Strokes
   ※ 그리기 모드 밖에서 Max 기본 Ctrl+Shift+Z 는 'Zoom Extents All'
   ※ 그리기 중 Ctrl+Z 와 Alt+휠은 함께 설치되는 RAKeys.dll 로 동작 (3ds Max 2025 이상 포함)
