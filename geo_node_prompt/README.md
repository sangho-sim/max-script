# Geo Node Prompt

프롬프트(자연어 문장)를 입력하면 Blender **지오메트리 노드(Geometry Nodes)** 구조를
자동으로 만들어 선택한 오브젝트에 모디파이어로 붙여주는 애드온.

- **오프라인 모드**: 인터넷 없이, 내장된 규칙(키워드 매칭) 템플릿만으로 동작.
- **하이브리드 모드(기본값)**: 규칙에 안 맞는 프롬프트는 Claude API로 보내 노드 구조(JSON)를
  생성 — 환경설정에서 "AI 사용 허용"을 켜고 API 키를 넣어야 동작.
- **AI 강제 모드**: 규칙 매칭을 건너뛰고 항상 Claude API 사용.
- 생성된 모디파이어는 **온/오프 토글**(패널 버튼, 또는 모디파이어 패널의 눈 아이콘)로
  뷰포트/렌더에서 켜고 끌 수 있고, 애드온 자체도 Blender Preferences > Add-ons 에서
  보통의 애드온처럼 켜고 끌 수 있다.

## 설치

1. `geo_node_prompt` 폴더 전체를 zip으로 압축한다 (`geo_node_prompt.zip`,
   폴더 자체가 최상위에 오도록).
2. Blender `Edit > Preferences > Add-ons > Install...` 에서 그 zip을 선택.
3. 목록에서 "Geo Node Prompt" 를 체크해 활성화.
4. (선택) AI 하이브리드/강제 모드를 쓰려면, 같은 환경설정 패널에서
   "AI(Claude) 사용 허용" 체크 후 Anthropic API 키를 입력. API 호출은
   사용자 계정으로 과금되며, 키는 Blender 로컬 설정에만 저장되고 저장소에는
   들어가지 않는다.

## 사용법

1. 메쉬 오브젝트를 선택한다.
2. 3D 뷰포트 오른쪽 사이드바(`N` 키) > **Geo Prompt** 탭을 연다.
3. 모드를 고르고, 프롬프트를 입력한다. 예:
   - "표면에 노이즈로 울퉁불퉁하게 해줘"
   - "풀을 스캐터해서 뿌려줘"
   - "이 오브젝트를 일렬로 배열해줘"
   - "subdivision으로 둥글게 만들어줘"
   - "다른 오브젝트로 구멍을 뚫어줘 (boolean)"
4. **생성** 버튼을 누르면 새 Geometry Nodes 모디파이어가 추가된다.
5. 생성된 모디파이어는 모디파이어 패널에서 노출된 입력값(Strength, Density,
   Count 등)을 직접 조절할 수 있고, Geo Prompt 패널의 토글 버튼이나 모디파이어
   패널의 눈 아이콘으로 바로 켜고 끌 수 있다.

## 내장 오프라인 템플릿

`templates.py` 에 키워드 기반으로 정의되어 있다 (한/영 혼용 키워드 매칭):

| 템플릿 | 키워드 예시 |
| --- | --- |
| 노이즈 디스플레이스 | 노이즈, 울퉁불퉁, bumpy, noise |
| 포인트 스캐터 | 스캐터, 흩뿌려, scatter, instance |
| 축 방향 배열 | 배열, 복제, array |
| 서브디비전 스무스 | 서브디비전, 둥글게, subdivision |
| 쉐이드 스무스 | 쉐이드 스무스, shading |
| 불리언 컷 | 불리언, 구멍, boolean |
| 익스트루드 두께 | 두께, 돌출, extrude |
| 랜덤 삭제 | 랜덤 삭제, 깨진, broken |

새 템플릿을 추가하려면 `templates.py`에 `_xxx_spec(prompt)` 함수와 `TEMPLATES`
리스트 항목만 추가하면 된다. 노드 스펙 형식은 `templates.py` 모듈 docstring 참고.

## AI(하이브리드) 백엔드 동작 방식

1. 프롬프트를 오프라인 규칙으로 먼저 매칭 시도 (HYBRID/OFFLINE 모드).
2. 매칭 실패 + AI 허용 상태면, `ai_backend.py`가 Claude API에 "허용된 노드
   타입/소켓 타입 화이트리스트 + JSON 스키마"를 시스템 프롬프트로 함께 보내
   노드 그래프 JSON을 받아온다.
3. 받은 JSON은 `validate_spec()`으로 구조와 노드 타입 화이트리스트를 검증한
   뒤에만 실제 노드 트리로 조립된다 (`node_builder.py`). 화이트리스트에 없는
   노드 타입이나 구조가 깨진 응답은 거부되고 에러로 보고된다.

## 제한 사항 / 알려진 이슈

- `node_builder.py`는 Blender **4.0 이상**의 `node_tree.interface` API를
  사용한다 (3.x는 지원하지 않음).
- 소켓 이름은 Blender 버전에 따라 미묘하게 달라질 수 있다. 특정 Blender
  버전에서 노드/소켓 이름이 다르면 `templates.py`의 해당 스펙만 수정하면 된다.
- 이 저장소 환경에는 Blender 실행 파일이 없어 실제 Blender 안에서의 동작은
  검증하지 못했다 (오프라인 템플릿 매칭/스펙 검증 로직은 `bpy` 스텁으로
  단위 테스트 완료). 실사용 전에 Blender에서 각 템플릿 프롬프트로 한 번씩
  직접 생성해보는 것을 권장한다.
- `scatter`/`array` 템플릿은 임시 플레이스홀더 지오메트리(아이코스피어, 또는
  원본 지오메트리 자체)를 인스턴스로 쓴다 — 실제 사용할 오브젝트로 바꾸려면
  생성된 노드 트리를 열어 해당 노드를 직접 교체하면 된다.
