# Geo Node Prompt

"문어다리", "나선", "사슬" 같은 짧은 **한글 키워드**를 입력하면 Blender
**지오메트리 노드(Geometry Nodes)** 구조를 자동으로 만들어 모디파이어로 붙여주는 애드온.
유튜브 지오노드 튜토리얼에서 자주 쓰는 효과를 "레시피"로 미리 만들어 두고 키워드로 부른다.

- **레시피만 모드**: 인터넷 없이, 내장 레시피만으로 동작.
- **레시피 우선, 없으면 AI (기본값)**: 레시피에 없는 표현은 Claude API가 먼저 레시피 중에서
  고르고, 맞는 게 없을 때만 노드 그래프를 새로 짠다 — 환경설정에서 "AI 사용 허용"을 켜고 API
  키를 넣어야 동작.
- **AI 강제 모드**: 레시피 매칭을 건너뛰고 항상 Claude API 사용.
- 생성된 모디파이어는 **온/오프 토글**(패널 버튼, 또는 모디파이어 패널의 눈 아이콘)로
  뷰포트/렌더에서 켜고 끌 수 있고, 애드온 자체도 Blender Preferences > Add-ons 에서
  보통의 애드온처럼 켜고 끌 수 있다.

## 설치

1. `geo_node_prompt` 폴더 전체를 zip으로 압축한다 (`geo_node_prompt.zip`,
   폴더 자체가 최상위에 오도록).
2. Blender `Edit > Preferences > Add-ons > Install...` 에서 그 zip을 선택.
3. 목록에서 "Geo Node Prompt" 를 체크해 활성화.
4. (선택) AI 하이브리드/강제 모드를 쓰려면, 같은 환경설정 패널에서
   "AI(Claude) 사용 허용" 체크 후 Anthropic API 키를 입력. API 호출은
   사용자 계정으로 과금되며, 키는 Blender 로컬 설정에만 저장되고 저장소에는
   들어가지 않는다.

## 사용법

1. 3D 뷰포트 오른쪽 사이드바(`N` 키) > **Geo Prompt** 탭을 연다.
2. 키워드를 입력하고 **지오메트리 노드 생성**을 누른다. 예:
   - `문어다리`, `문어다리 6개 길게`, `굵은 촉수 12가닥`
   - `스프링 10바퀴`, `쇠사슬 20개`, `큰 바위`
   - (메쉬 선택 후) `레고처럼`, `타노스처럼 사라지는`, `넝쿨이 자라나는`, `풀 흩뿌리기`
   - 조합: `문어다리 울퉁불퉁` (문어다리 위에 노이즈 변형을 이어 붙임)
3. 문어다리·나선·사슬·바위처럼 **새 형태를 만드는 레시피는 3D 커서 위치에 새 오브젝트**를
   만든다. 복셀·분해처럼 **변형 레시피는 선택한 메쉬**에 붙는다. 덩굴·흩뿌리기는 선택한 메쉬
   표면 위에 만들고, 선택이 없으면 바닥 평면을 새로 만든다.
4. 모디파이어 패널에 한글 이름의 입력(다리 개수, 길이, 굵기, 진행 ...)이 노출되어 바로
   조절할 수 있다. 노드 에디터에서 열면 단계별 프레임("1. 다리 한 가닥 뼈대" ...)으로
   나뉘어 있어 튜토리얼처럼 따라 읽을 수 있다.
5. 키워드가 안 맞으면 "이걸 찾으셨나요?" 후보 버튼이 뜨고, 패널의 **레시피 목록**에서 직접
   골라 만들 수도 있다. 띄어쓰기("문어 다리"), 오타("문어다라")도 웬만큼 알아듣는다.

## 레시피

| 레시피 | 키워드 예시 | 종류 | 조절 값 |
| --- | --- | --- | --- |
| 문어다리 | 문어다리, 촉수, 텐타클, 오징어다리 | 새 형태 | 다리 개수, 길이, 굵기, 꿈틀거림, 말림, 빨판, 시드 |
| 나선 | 나선, 스프링, 용수철, 코일 | 새 형태 | 회전 수, 높이, 반지름, 끝 반지름, 굵기 |
| 사슬 | 사슬, 쇠사슬, 체인 | 새 형태 | 고리 수, 고리 크기, 굵기 |
| 바위 | 바위, 암석, 돌멩이, rock | 새 형태 | 크기, 울퉁불퉁함, 디테일, 납작함, 시드 |
| 복셀화 | 복셀, 레고, 블록화, 마인크래프트 | 선택 메쉬 변형 | 블록 크기, 틈 |
| 분해 효과 | 분해, 흩어지는, 디졸브, 타노스 | 선택 메쉬 변형 | 진행(0~1 애니메이션), 날아가는 거리, 퍼짐, 시드 |
| 덩굴 성장 | 덩굴, 넝쿨, 자라나는, 성장 | 표면 위 | 줄기 수, 길이, 성장(0~1 애니메이션), 구불거림, 굵기, 시드 |
| 흩뿌리기 | 흩뿌리기, 스캐터, 풀, 자갈, 잔디 | 표면 위 | 밀도, 최소/최대 크기, 흩뿌릴 오브젝트, 시드 |
| 울퉁불퉁 노이즈 · 배열 복제 · 부드럽게 · 쉐이드 스무스 · 구멍 뚫기 · 두께 주기 · 랜덤 삭제 | 예전 템플릿 키워드 | 선택 메쉬 변형 | |

숫자와 형용사도 읽는다: `6개`, `여섯 개`, `10바퀴`, `3m` / `길게`·`짧게`, `굵게`·`가늘게`,
`많이`·`적게`, `크게`·`작게`, `꼬불꼬불`·`살짝`, `돌돌 말린`.

새 레시피는 `recipes/` 에 `Recipe` 를 상속한 클래스(별칭, 파라미터, `build(g, P)`)를 만들고
`recipes/__init__.py` 의 `BUILTIN` 에 넣으면 된다. 노드는 `graph.py` 의 작은 빌더로 짠다.

## AI(하이브리드) 백엔드 동작 방식

1. 키워드를 레시피로 먼저 매칭 시도 (`korean.py`, 레시피만/하이브리드 모드).
2. 매칭 실패 + AI 허용 상태면, Claude 에게 레시피 목록을 주고 도구 호출(`choose_recipes`)로
   알맞은 레시피와 값을 고르게 한다 ("바다 괴물의 꿈틀대는 팔" -> 문어다리).
3. 맞는 레시피가 없으면 허용된 노드 화이트리스트 + JSON 스키마 + 예시로 노드 그래프 JSON 을
   새로 받아 `validate_spec()` 으로 검증하고 엄격 모드로 조립한다. 조립이 실패하거나 결과가
   비면 오류 내용을 붙여 한 번 더 고치게 하고, 그래도 안 되면 만든 것을 모두 되돌린다.
4. AI 가 새로 만든 결과는 **레시피로 저장** 버튼으로 사용자 설정 폴더
   (`config/geo_node_prompt/user_recipes`)에 저장되어, 다음부터는 같은 키워드로 AI 없이 만든다.
5. 매칭에 실패한 키워드는 `config/geo_node_prompt/unmatched.txt` 에 남는다 (외부 전송 없음).
   다음에 만들 레시피를 고를 때 참고용.

## 제한 사항 / 알려진 이슈

- `node_builder.py`는 Blender **4.0 이상**의 `node_tree.interface` API를
  사용한다 (3.x는 지원하지 않음).
- 소켓 이름은 Blender 버전에 따라 미묘하게 달라질 수 있다. 특정 Blender
  버전에서 노드/소켓 이름이 다르면 `templates.py`의 해당 스펙만 수정하면 된다.
- 레시피 15종, 한글 키워드 해석, 오퍼레이터, AI 경로(가짜 응답)는 Blender 4.2.23 / 4.5.14 /
  5.0.1 (`pip install bpy==<버전>`) 헤드리스 환경에서 실제로 빌드·평가해 검증했다.
  같은 검사를 직접 돌리려면 저장소 루트에서:
  `blender -b --factory-startup --python geo_node_prompt/tests/check_recipes.py`
  (`RENDER_DIR=폴더` 를 주면 레시피별 렌더 PNG 도 저장)
  `blender -b --factory-startup --python geo_node_prompt/tests/check_templates.py`
  UI 패널 표시는 헤드리스로 확인할 수 없으니 Blender에서 한 번 열어보는 것을 권장한다.
- 흩뿌리기 레시피는 "흩뿌릴 오브젝트"가 비어 있으면 작은 아이코스피어를 쓴다. 모디파이어
  패널에서 오브젝트를 고르면 그 오브젝트로 바뀐다.
- 새 형태 레시피 결과에는 재질이 없다. 필요하면 오브젝트에 재질을 직접 넣는다.
